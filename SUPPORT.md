# Getting help · အကူအညီရယူရန်

**Try the studio first:** most questions answer themselves in two minutes
of drawing — <https://thiha-lynn.github.io/myanmar-glyph-studio/> (press
**Help** in the app for install/usage guides and every keyboard shortcut).

| I want to… | Go to |
|---|---|
| Ask a question, share an idea, show a font | [Discussions](https://github.com/Thiha-Lynn/myanmar-glyph-studio/discussions) |
| Report something broken | [Bug report](https://github.com/Thiha-Lynn/myanmar-glyph-studio/issues/new?template=bug-report.md) |
| Report text that renders wrongly (stacks, kinzi, marks) | [Shaping report](https://github.com/Thiha-Lynn/myanmar-glyph-studio/issues/new?template=shaping-report.md) |
| Claim glyphs to draw for a community font | [Glyph contribution](https://github.com/Thiha-Lynn/myanmar-glyph-studio/issues/new?template=glyph-contribution.md) |
| Suggest a feature | [Feature request](https://github.com/Thiha-Lynn/myanmar-glyph-studio/issues/new?template=feature-request.md) |
| Report a security problem privately | See [SECURITY.md](SECURITY.md) |
| Learn how to contribute | [CONTRIBUTING.md](CONTRIBUTING.md) |

Burmese is welcome everywhere — write issues and discussions in whichever
language you think in. မြန်မာလိုရေးလို့ရပါတယ်။

For building fonts locally, [README.md](README.md#build-a-real-font-from-your-project)
covers the pipeline; [docs/TESTING.md](docs/TESTING.md) covers the test
tools; [docs/PLATFORMS.md](docs/PLATFORMS.md) covers using the fonts on
each OS, game engine, and app framework.
