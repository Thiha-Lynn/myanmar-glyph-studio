Draw once, get many faces. A sketch in the studio is stored as centre-lines plus a pen — so the same drawing can come out as a round sans, a squircle display face, a slab, and a whole weight axis. This page is that idea, live.

🖊 The pen, in your hands — ကလောင်ကို စမ်းကြည့်ပါ

This is the studio's actual outline code — the same maths pipeline/json_to_ufo.py mirrors at build time — expanding the sample font's real က around its skeleton. Drag the knobs.

A full build adds what a preview cannot: curve fitting, overlap removal, generated shaping rules, kerning and the validation suite. The nib and warp you see here are exactly what meta.pen and --squircle do.

Every one traced in the browser, built by the pipeline, and validated to zero failures on 1,486 spec clusters and 12,450 real words before it gets to sit here. Each card wears its own recipe.

🍳 Cook your own — ကိုယ်ပိုင်စတိုင် ချက်ကြည့်ပါ

The knobs above are ordinary command-line flags. From a checkout (pip install -e ".[dev]"):

# the whole inventory in your flavour — weight scales the pen,
# --squircle warps the skeletons, meta.pen squares the nib
mgs-sample --font-name "My Style" --weight 1.8 --squircle 4 out/

# one drawing → Light / Regular / Bold masters + a variable font
mgs-variable MyFont.glyphstudio.json build/

# then prove it before you ship it
mgs-validate build/MyFont-Regular.ttf

The nib lives in your project file as meta.pen (2 round · 4 squircle · 8 slab, anything 2–12) — the studio previews it while you draw, the pipeline builds with it, and docs/ARCHITECTURE.md maps where all of this lives.

Fonts are OFL 1.1 (letterform skeletons extracted from SIL Padauk, credited in each OFL.txt). Toolkit MIT. Preview runs web/js/outline.js — the file the pipeline mirrors.
