Type specimen · စာလုံးပုံစံ

Myanmar faces, set in Myanmar literature

Every face below was drawn stroke by stroke in a browser and compiled by this repository. A specimen usually shows a typeface at its best; this one shows it doing its job — the alphabet, a size ramp, running text, and the clusters that break Myanmar fonts. The words are classical Burmese, never filler.

မြန်မာ

The alphabet · ဗျည်း ၃၃ လုံး

Thirty-three consonants, the vowel signs, and the digits — the parts a contributor actually draws. Everything else in the font is built from these by rule.

Waterfall · အရွယ်အစား

The same line from 84px down to 15px. A face that holds together large and falls apart small is a display face; one that survives the bottom of this ramp can set a book.

Running text · စာပိုဒ်

Narrative prose from the Jātaka cycle — the Buddha's past lives, in classical Burmese. Texture is the only thing that matters here: even colour, no rivers, no cluster punching a hole in the line.

Display · ခေါင်းစဉ်

The hard part · ခက်ခဲသော အက္ခရာများ

Stacked consonants, the four medials, kinzi, and the vowel that takes four different shapes depending on what precedes it. This is where Myanmar fonts fail, so it is the part worth staring at.
