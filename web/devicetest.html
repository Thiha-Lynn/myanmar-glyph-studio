Device shaping test

Our CI checks Myanmar shaping with HarfBuzz — the engine Android, Chrome and Linux use. Windows (DirectWrite) and Apple (CoreText) can disagree, and only real devices reveal it. This page renders every cluster that has ever broken, tells you what correct looks like, and writes the report for you.

Installed the font first? On Windows right-click → Install; macOS double-click → Install Font; Android/iOS need a font-install app. If the picked font is not installed the browser falls back silently — check the letterforms actually change when you switch.
